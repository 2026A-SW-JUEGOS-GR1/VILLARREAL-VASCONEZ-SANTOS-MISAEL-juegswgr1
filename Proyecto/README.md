## Crazy Basketball Game

Un juego de plataformas vertical hecho con Phaser 3.

## Cómo jugar

Usa las teclas de dirección para moverte:
- **← →** Moverse a los lados
- **↑** Saltar
- **↓** Bajar

## Coleccionables

- **Balón** — recógelos para tener munición
- **Aro** — recoge un aro para anotar (consume un balón)
- **Estrella** — colecciónalas

## Enemigos

- **Jordan grande** — te quita todos los balones
- **Jordan pequeño** — te elimina del juego

## Reglas

- Si sales por arriba o abajo de la pantalla, es Game Over
- No puedes salirte por los lados
